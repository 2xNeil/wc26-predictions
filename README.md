Pick the winner and score for every match, lock in your picks before kickoff, and see how you stack up against your rival once results come in.

Built as a single static HTML page, hosted on GitHub Pages, with Google Sheets as a rudimentary database.

## How it works

- Logging in requires a 4-digit PIN
- Once in, you're shown a swipeable carousel of upcoming matches not predicted yet. 
- Pick a winner and a scoreline for each match. Your opponent's pick for a match stays hidden until you've made your own pick for that match.
- A scorecard view shows the match results and who won the prediction round

## Scoring

| Pick | Points |
|---|---|
| Correct winner | +5 |
| Exact scoreline | +10 |
